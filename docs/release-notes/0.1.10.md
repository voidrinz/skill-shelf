# What's New

- Fixed macOS update installation failing while copying the application bundle. Installation now treats `app.asar` as a physical archive, so Electron's virtual filesystem no longer interrupts preparation.
- Update backup cleanup uses the same native filesystem access. A failed installer handoff removes temporary installation files, and temporary preparation cleanup no longer overrides the installation result.

## Updating

Apple Silicon users on v0.1.9 or earlier should install this release manually once. The updaters in v0.1.8 and v0.1.9 can fail before the application exits while copying `app.asar`; retrying does not replace the installed updater code. Earlier versions also require a manual upgrade. This release includes the fix for future in-app updates.

Quit Skill Shelf, open the installer, and replace the app in a writable Applications folder. Your Skill shelf, settings, and other saved application data are retained.

Intel users can continue using v0.1.6; new releases support Apple Silicon only.
