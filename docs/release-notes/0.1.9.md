# What's New

- AI configuration sync now transfers provider API keys and connection enabled states alongside models and preferences. Keys are protected with your sync password in file exports and WebDAV snapshots. Previews show only whether a key is present and whether the connection is enabled.
- Enter the same sync password of at least 8 characters on both computers. It is separate from your WebDAV password and is kept only while the Sync page is open. Other Skill metadata remains readable in the snapshot.
- You can opt out of importing or uploading AI configuration. Imports of older metadata documents continue to preserve local credentials. Model verification results and conversations remain local, and changing a key resets its verification results.
- The Packs sidebar now supports collapsing and resizing, remembers its width separately from the Skills sidebar, and keeps your selected Pack and search when reopened. Keyboard controls preserve focus, and the sidebar remains available while the AI panel is open.
- Packs are grouped under **My Packs**, with a count and a nearby action for creating a Pack.

## Updating

Apple Silicon users on v0.1.8 can open Settings > About to download this update, then choose **Restart and update**. Open terminal sessions end during the restart. Your Skill shelf and settings are retained.

Apple Silicon users on v0.1.7 or earlier must install this release manually once to enable future in-app updates. Quit Skill Shelf, open the installer, and replace the app in a writable Applications folder. Your saved data is retained.

Intel users can continue using v0.1.6; new releases support Apple Silicon only.
