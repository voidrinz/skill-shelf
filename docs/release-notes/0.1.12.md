# What's New

- Fixed builds that could produce an empty main-process entry and prevent Skill Shelf from starting. Development and production builds now use a matching CommonJS application entry.
- Pull data now opens a cloud browser that separates the latest shared data from upload history. Choose a backup by computer, upload time, and Skill/Pack counts, then preview how it applies to your local organization.
- Cloud imports default to merging with local data. You can explicitly choose replacement for matching Skill management fields and same-name Pack descriptions and membership. Unrelated Skills and Packs remain unchanged; Skill files and installations are not added or removed.
- Upload data now sends all app preferences and AI configuration in one operation without an upload preview. It merges management data into the shared snapshot and saves a separate original backup for every upload, including repeated uploads from the same computer. Uploads do not modify local stores.
- New version 4 snapshots include AI provider API keys and enabled states as plain-text configuration in exports and cloud backups. New exports and uploads need no encryption password. Previews show only key presence; older encrypted backups ask for their original password when opened, and file import retries reuse the selected document.
- WebDAV connections can use a service endpoint such as Nutstore's DAV address. Missing application and backup directories are created automatically, existing snapshot locations remain usable, and conditional writes retain concurrency protection.
- Upload history recovers older backup files omitted from previous indexes. If shared data uploads successfully but its backup cannot be indexed, the app reports partial success separately.

## Updating

Apple Silicon users on v0.1.10 or v0.1.11 can open Settings > About to download this update, then choose **Restart and update**. If your current build does not open, install this release manually. Open terminal sessions end during an in-app restart. Your Skill shelf and settings are retained.

Apple Silicon users on v0.1.9 or earlier should install this release manually once. Quit Skill Shelf, open the installer, and replace the app in a writable Applications folder. Your saved application data is retained, and this release includes the native filesystem fix for future in-app updates.

Intel users can continue using v0.1.6; new releases support Apple Silicon only.
