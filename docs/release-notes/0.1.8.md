# What's New

- New macOS releases support Apple Silicon (M1 and later) only. Intel downloads remain available in v0.1.6.
- Signed updates now support Apple Silicon-only releases while retaining compatibility with historical manifests that contain both architectures.
- The website offers a single Apple Silicon download, and release builds no longer depend on an Intel build completing.
- This release also includes the changes from the unpublished v0.1.7: expanded metadata sync for Packs and optional AI preferences, repeatable update checks, compact Skill descriptions with translation controls, and corrected macOS menu bar icons. See the [v0.1.7 notes](https://github.com/voidrinz/skill-shelf/blob/main/docs/release-notes/0.1.7.md) for details.

## Updating

Apple Silicon users on v0.1.7 or earlier must install this release manually once. The updaters in v0.1.6 and v0.1.7 require both architectures in the signed manifest and cannot install an Apple Silicon-only release. This release accepts the new manifest for future in-app updates. Your Skill shelf and settings are retained.

To install manually, quit Skill Shelf, open the installer, and replace the app in Applications. Copy the app into a writable Applications folder before using future in-app updates.

Intel users can continue using v0.1.6; newer builds are available for Apple Silicon only.
