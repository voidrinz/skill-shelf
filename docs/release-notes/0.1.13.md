# What's New

- Projects now have an instruction editor for AGENTS.md and CLAUDE.md. Keep shared rules in AGENTS.md and connect Claude with its native @AGENTS.md import while preserving existing instructions. Saves check for external edits and back up previous file contents.
- Packs now opens a built-in Default collection plus additional Packs. Every import creates a complete independent Skill copy in the selected Pack and folder. Existing shared members migrate into separate copies, preserving organization and keeping deployments on the original copy.
- Skills and Packs now share the same icon, list, and column views, folder navigation, grouping, context menus, selection, and drag interactions. Each Pack folder retains its own view and layout settings. Deleting a Pack removes its owned copies after confirmation; active linked deployments must be removed first.
- Sync and file exports now include every Skill in Default and all other Packs with their complete files, descriptions, folders, colors, tags, positions, and view settings. Copies stay independent across Packs and repeated imports. Previews show additions, file changes, and organization conflicts, with backups and rollback protecting local data.
- Export Pack shares one collection and its Skill files without app preferences, installed Skill organization, AI configuration, or credentials. The recipient can preview and import the file through Settings > Sync.
- Sorting defaults to descending, with folders always ahead of individual Skills. Ascending and descending apply within each item kind, and saved sorting preferences remain respected.
- Fixed Packs page loading failures and replaced its old loading grid with a complete workspace skeleton. The sidebar, page header, navigation, search, and content area retain their positions through loading, including sidebar preferences and narrower windows.

## Sync Compatibility

New sync files and cloud snapshots use version 5. Update participating computers to this release before exchanging new snapshots. Versions 1 through 4 remain importable. Older metadata-only backups can restore available local copies but cannot recreate missing Skill files; upload again from the updated app to include them.

Original installed Skill files, deployment records, machine paths, WebDAV credentials, and project instruction files are excluded from sync. AI configuration remains plain text in full sync exports and cloud backups; selected-Pack exports exclude it.

## Updating

Apple Silicon users on v0.1.10 or later can open Settings > About to download this update, then choose **Restart and update**. Open terminal sessions end during the restart. Your saved shelf and settings are retained, and the previous Packs state is backed up before migration.

Apple Silicon users on v0.1.9 or earlier, or whose current build cannot open, should install this release manually. Quit Skill Shelf, open the installer, and replace the app in a writable Applications folder. Your saved application data is retained.

Intel users can continue using v0.1.6; new releases support Apple Silicon only.
