# What's New

- Metadata sync now includes Packs and optional AI preferences: model lists, default role models, translation language, and context mode. Each computer retains its API keys, connection enabled states, and conversations. Older metadata exports remain importable.
- Pack sync previews matching and skipped members, preserves local-only members on import and cloud-only references on upload, and lets you resolve description conflicts. Imports back up affected metadata and restore earlier changes if a later write fails. WebDAV connection loading can also be retried after a failure.
- Settings > About keeps **Check for updates** available beside download and restart actions. Rechecking preserves a verified download when it still matches the release, and a failed check keeps the previous update available with a separate warning.
- Skill descriptions use a compact preview with expandable text, quick access to translation, and a menu for choosing languages or refreshing a saved translation. You can switch between original and translated descriptions while keeping the original readable during translation.
- macOS menu bar icons preserve their native dimensions and Retina images. The development icon uses a clearer transparent template with a development marker.

## Updating

If you use v0.1.6, open Settings > About to download this update, then choose **Restart and update**. Open terminal sessions will end during the restart. Your Skill shelf and settings are retained.

For v0.1.5 or earlier, install this release manually once to enable future in-app updates. Copy Skill Shelf into a writable Applications folder before using in-app installation.
