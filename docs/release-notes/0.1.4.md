# What's New

- Skill Shelf opens without requesting macOS Keychain access. Saving API keys
  and AI conversations also no longer requires Keychain authorization.
- API keys and conversations are now saved locally without encryption, in
  files restricted to your macOS user account.
- To keep AI data saved by an older version, open Settings > AI > Providers
  and choose **Restore previous AI data**. macOS may ask for permission during
  this one-time recovery. Original encrypted files are retained as backups;
  a failed recovery can be retried.

- Recovered conversations appear immediately in the AI assistant, including
  when it was already open before recovery.
