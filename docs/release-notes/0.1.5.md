# What's New

- The workbench now distinguishes detected Agent programs from directories left on disk. Review shared Skill coverage, Agent-only Skills, program detection evidence, and file or link issues, and open Agent directories directly from the workbench.
- Transfer Skill organization between computers with file export/import or your own WebDAV storage. Preview changes and resolve conflicts before merging folders, tags, canvas positions, descriptions, and translations. Skill files, installation paths, and account keys stay on each computer.
- The installed Skills sidebar can be resized, collapsed, and restored. Search and update filters show matching Skills across folders, and search fields have consistent clear and Escape behavior.
- Loading placeholders now follow the layout of the workbench, Skill lists, discovery pages, projects, and file browser.
- Settings > About now shows the app version, project links, and clearer update actions. A dot on Settings highlights an available app update.
- Development builds use separate application data and identity from the installed release. Form controls also have improved contrast across themes.
