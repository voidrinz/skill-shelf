# What's New

- macOS updates can now be downloaded and installed from Settings > About. Skill Shelf verifies an independently signed update manifest, downloads the ZIP for your Mac, and checks the archive and application before offering **Restart and update**.
- Update progress now includes download, verification, and installation states. About shows distinct messages for network, verification, permission, installation, and rollback failures, with actions to retry the appropriate step.
- Restarting to update asks for confirmation because open terminal sessions will end. The installer preserves the previous application and restores it if the new version fails to become ready. Your Skill shelf and settings are retained.

## First Upgrade

Install v0.1.6 manually once if you are using v0.1.5 or earlier. Those versions open the release download page and cannot install the new updater into themselves. Later signed releases can be installed in-app.

Copy Skill Shelf into a writable Applications folder before using in-app installation. Applications launched from a DMG, a translocated directory, or a protected folder cannot replace themselves.
