# What's New

- Saving a WebDAV connection now remembers its password for future launches without accessing the system Keychain. Connection credentials are stored locally as unencrypted JSON with owner-only file permissions and remain separate from your AI configuration encryption password.
- Existing system-encrypted WebDAV connections retain their URL and username. Enter the WebDAV password once more and save the connection before testing, uploading, or pulling data. Reading the old configuration leaves the original file intact.
- Sync results and errors now use floating notifications, including errors while a preview is open. Dismissing a notification keeps the preview available for retry, and notifications no longer shift the page layout.
- AI configuration encryption instructions now explain how to choose a password for export or upload and reuse it on another computer for import or pull. Password errors mark and focus the encryption field after the operation finishes.
- Input placeholders have clearer colors in both themes. Error notifications use alert semantics, and notification interactions preserve the dialog underneath.

## Updating

Apple Silicon users on v0.1.10 can open Settings > About to download this update, then choose **Restart and update**. Open terminal sessions end during the restart. Your Skill shelf and settings are retained.

Apple Silicon users on v0.1.9 or earlier should install this release manually once. Quit Skill Shelf, open the installer, and replace the app in a writable Applications folder. Your saved application data is retained, and this release includes the native filesystem fix for future in-app updates.

Intel users can continue using v0.1.6; new releases support Apple Silicon only.
